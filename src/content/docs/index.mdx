## What twinny does

<CardGrid stagger>
  <Card title="Code completion" icon="seti:json">
    Fill-in-the-middle suggestions as you type, with context from open files, recent edits and IntelliSense. Press Tab to accept.
  </Card>
  <Card title="Inline edit" icon="pencil">
    Press Ctrl+I, describe a change, and review it as a diff in the editor. Accept, reject, or refine.
  </Card>
  <Card title="Chat" icon="comment">
    Ask about your code with files, symbols, problems, git changes and terminal output attached with @.
  </Card>
  <Card title="Workspace index" icon="magnifier">
    Embed the workspace so chat can find the code a question is about, ranked by a local reranker.
  </Card>
  <Card title="Code review and commits" icon="github">
    Review the working tree, a branch or a GitHub pull request, and write commit messages.
  </Card>
  <Card title="Terminal" icon="laptop">
    Write a command from a description, or fix the last error with the output attached.
  </Card>
  <Card title="Devices" icon="random">
    Use the GPU in another of your computers over an encrypted peer-to-peer link. No account, no relay.
  </Card>
  <Card title="Private by default" icon="approve-check">
    Everything runs against a server you control. No telemetry, no sign-in, MIT licensed.
  </Card>
</CardGrid>
