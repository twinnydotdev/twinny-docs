title: 支持 twinny
description: 购买许可证，或其他支持 twinny 项目的方式。
---

感谢你使用 twinny！

twinny 以 MIT 许可证免费开源，并将一直如此。如果它对你有帮助，最好的支持方式是**购买许可证**：个人开发者可一次性 $29 购买 [Personal](https://twinny.dev/#pricing)，网关超过五位开发者时购买 [Team 席位](https://twinny.dev/#pricing)，或为整个组织购买 [Enterprise](https://twinny.dev/#contact)。许可证增加席位，并开启[团队策略](/twinny-docs/teams/policy/)、[记录](/twinny-docs/teams/recording/)和[插件](/twinny-docs/teams/plugins/)；见[许可与席位](/twinny-docs/teams/licensing/)。还没决定？[30 天试用](https://twinny.dev/#trial)无需银行卡。

其他回馈方式：

- 在 [GitHub](https://github.com/twinnydotdev/twinny) 上**给仓库加星**并告诉其他人。
- 在 [issues 页面](https://github.com/twinnydotdev/twinny/issues)**报告 bug 和想法**。附上所用模型和服务器的清晰报告是最有帮助的。
- **分享有效的配置。** 如果某个本文档未列出的模型或服务器对你很好用，请开 issue 或 pull request 让其他人也能用。
- **贡献**代码或翻译；见[参与贡献](/twinny-docs/zh-cn/reference/contributing/)。
- 在 [X](https://x.com/twinnydotdev) 上**关注**更新。
