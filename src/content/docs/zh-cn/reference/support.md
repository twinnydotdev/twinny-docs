感谢你使用 twinny！

twinny 以 MIT 许可证免费开源，并将一直如此。如果它对你有帮助，可以通过以下方式回馈：

- 在 [GitHub](https://github.com/twinnydotdev/twinny) 上**给仓库加星**并告诉其他人。
- 在 [issues 页面](https://github.com/twinnydotdev/twinny/issues)**报告 bug 和想法**。附上所用模型和服务器的清晰报告是最有帮助的。
- **分享有效的配置。** 如果某个本文档未列出的模型或服务器对你很好用，请开 issue 或 pull request 让其他人也能用。
- **贡献**代码或翻译；见[参与贡献](/twinny-docs/zh-cn/reference/contributing/)。
- 在 [X](https://x.com/twinnydotdev) 上**关注**更新。
