## twinny 能做什么

<CardGrid stagger>
  <Card title="代码补全" icon="seti:json">
    边输入边获得填空式（fill-in-the-middle）建议，结合打开的文件、最近的编辑和 IntelliSense 上下文。按 Tab 接受。
  </Card>
  <Card title="内联编辑" icon="pencil">
    按 Ctrl+I 描述修改，在编辑器中以 diff 形式审阅。接受、拒绝或微调。
  </Card>
  <Card title="对话" icon="comment">
    用 @ 附加文件、符号、问题、git 变更和终端输出，就你的代码提问。
  </Card>
  <Card title="工作区索引" icon="magnifier">
    为工作区建立嵌入索引，让对话找到问题相关的代码，由本地重排序器排序。
  </Card>
  <Card title="代码审查与提交" icon="github">
    审查工作区、分支或 GitHub 拉取请求，并撰写提交信息。
  </Card>
  <Card title="终端" icon="laptop">
    根据描述编写命令，或附上输出修复最后一个错误。
  </Card>
  <Card title="设备" icon="random">
    通过加密的点对点连接使用你另一台电脑上的 GPU。无需账号，没有中继。
  </Card>
  <Card title="默认私密" icon="approve-check">
    一切都运行在你控制的服务器上。没有遥测，无需登录，MIT 许可证。
  </Card>
</CardGrid>
