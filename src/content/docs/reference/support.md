Thanks for using twinny!

twinny is free and open source under the MIT licence, and will stay that way. If it has been useful to you, there are a few ways to give back:

- **Star the repository** on [GitHub](https://github.com/twinnydotdev/twinny) and tell people about it.
- **Report bugs and ideas** on the [issues page](https://github.com/twinnydotdev/twinny/issues). A clear report with the model and server you used is the most helpful thing you can send.
- **Share what works.** If a model or server not listed in these docs works well for you, open an issue or a pull request so others can use it.
- **Contribute** code or translations; see [Contributing](/twinny-docs/reference/contributing/).
- **Follow along** on [X](https://x.com/twinnydotdev) for updates.
